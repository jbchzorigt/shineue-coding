# Тэмцээний илгээлтүүд: багшийн харагдац, CSV, хуулбар илрүүлэлт

Огноо: 2026-10-01
Төлөв: Дизайн батлагдсан, spec хянагдаж байна
Өмнөх ажил: `2026-09-30-vercel-deploy-design.md` (дууссан)

## Зорилго

Сурагчид тэмцээнд илгээсэн бодолт бүр `contest_submissions` хүснэгтэд аль хэдийн бичигддэг: Python код
эсвэл хэлхээний JSON, оноо, давсан тест, цаг. Гэхдээ үүнийг харах хуудас байхгүй. Энэ ажлаар багш, админ:

1. тэмцээн бүрийн бүх илгээлтийг сурагч, бодлогоор шүүж харна;
2. дүн болон бүх оролдлогыг CSV-ээр (Excel) татна;
3. ижил төстэй (хуулсан байж болзошгүй) бодолтын хосуудыг олно.

### Хэрэглэгчийн шийдвэрүүд

- Зорилго: багш харах, Excel/CSV татах, хуулбар илрүүлэх. Сурагч өөрийн өмнөх илгээлтийг харах нь энэ ажилд орохгүй.
- Хуулбар хайхдаа сурагч бүрийн бодлого тус бүрийн **шилдэг бодолтыг** (хамгийн өндөр оноотой, тэнцвэл хамгийн сүүлийнх) харьцуулна.
- Логик хэлхээний бодлогыг **бүтцээр нь** харьцуулна.
- CSV **хоёулаа**: «Дүн» ба «Бүх оролдлого».
- Ижил төстэйг хэмжих арга **A**: токен + хурууны хээ (winnowing, MOSS-той төстэй).

### Хүрээнээс гадуур

- Сурагчид өөрийн илгээлтийн түүхийг харуулах.
- Өөр тэмцээн, модулийн даалгавар хооронд харьцуулах (зөвхөн нэг тэмцээн доторх нэг бодлогын хүрээнд).
- Интернэтээс хуулсныг илрүүлэх, AI-аар бичсэнийг таних.
- Хуулбар гэж тэмдэглэх, оноо хасах зэрэг үйлдэл. Систем зөвхөн сэжигтэй хосыг харуулна; шийдвэрийг багш гаргана.
- Оролцогчоор бүртгүүлээгүй багшийн туршилтын илгээлт (одоо ч бүртгэгддэггүй, хэвээр).
- Хэлхээг зургаар (read-only canvas) харуулах. Томьёогоор харуулна.

### Амжилтын шалгуур

1. Тэмцээний удирдлагын хуудсан дээр «Илгээлтүүд» товч гарч, `/teacher/contests/<id>/submissions` руу орно.
2. «Илгээлтүүд» таб бүх оролдлогыг шинээс нь 100-аар хуудаслаж харуулна; сурагч, бодлогоор шүүгдэнэ; мөрийг дэлгэхэд Python код эсвэл хэлхээний томьёо харагдана.
3. «Хуулбар сэжиг» таб бодлого тус бүрээр ≥70%-ийн хосуудыг буурахаар жагсааж, хосыг дэлгэхэд хоёр бодолт зэрэгцэн харагдана.
4. Хувьсагчийн нэр сольсон, тайлбар/хоосон зай нэмсэн, дээр нь илүү код нэмсэн хуулбар ≥90% гарна. Огт өөр бодолт 70%-иас доош гарна. Багшийн эхлэлийн код ижил төстэйд тооцогдохгүй.
5. Хэлхээний хаалганы ID, байрлал, оролтын дараалал өөр боловч бүтэц ижил бол 100%.
6. «Дүн», «Бүх оролдлого» CSV Excel-д кирилл зөв, мөр/багана эвдрэлгүй нээгдэнэ; `=`-ээр эхэлсэн код томьёо болж ажиллахгүй.
7. Сурагч болон нэвтрээгүй хүн хуудас, CSV-д хандаж чадахгүй.
8. `npm test`, `tsc`, `lint` (алдаа 0), `next build` бүгд амжилттай; хөтөч дээрх шалгалт (§8) давсан.

## 1. Өгөгдөл

Шинэ хүснэгт, migration байхгүй. Бүгд `contest_submissions` (append-only), `contest_participants`,
`contest_problems`-ээс уншина. Тэмцээн устахад илгээлтүүд cascade-аар устдаг нь хэвээр.

Шинэ файл `src/lib/db/contest-submissions.ts` (`server-only`):

```ts
export interface SubmissionRow {
  id: number;
  uid: string;
  name: string | null;      // contest_participants.name
  email: string;            // contest_participants.email
  problem_id: string;
  code: string;             // Python код эсвэл хэлхээний JSON
  score: number;
  passed_tests: number;
  total_tests: number;
  submitted_at: number;     // epoch ms
}

/** Шинээс нь; шүүлт, хуудаслалттай. total нь шүүлтэд тохирох нийт тоо. */
listContestSubmissions(contestId, { uid?, problemId?, limit, offset }): Promise<{ rows: SubmissionRow[]; total: number }>

/** (uid, problem_id) тус бүрийн шилдэг нь: score desc, submitted_at desc, id desc. */
bestSubmissions(contestId): Promise<SubmissionRow[]>

/** CSV-д: бүгд, хуучнаас нь (submitted_at asc, id asc). */
allContestSubmissions(contestId): Promise<SubmissionRow[]>
```

`bestSubmissions` нь `DISTINCT ON (uid, problem_id)` ашиглана. Нэр, имэйлийг `contest_participants`-тай
join хийж авна (илгээлт бүр оролцогчийн мөртэй FK-ээр холбоотой).

## 2. Хуудас

`src/app/teacher/contests/[contestId]/submissions/page.tsx` (server component).

- Эрх: бусад `/teacher` хуудасны адил. Нэвтрээгүй бол `/login`, багш/админ биш бол `/` руу шилжинэ. Тэмцээн олдохгүй бол 404.
- URL параметр: `tab=attempts|similar` (анхдагч `attempts`), `student=<uid>`, `problem=<id>`, `page=<n>` (1-ээс). Буруу утгыг үл тоож анхдагчаар авна.
- Толгой: буцах товч («Тэмцээн удирдлага» → `/teacher/contests/<id>`), тэмцээний нэр, CSV хоёр товч, хоёр таб (холбоос).
- `/teacher/contests/[contestId]/page.tsx`-ийн «Бодлогууд» картын толгойд «Leaderboard»-ийн хажууд «Илгээлтүүд» товч нэмнэ.

### 2.1 «Илгээлтүүд» таб

- Шүүлтүүр: сурагчийн сонголт (оролцогчид, нэрээр) ба бодлогын сонголт — `<select>` бүхий GET форм (JS шаардахгүй).
- Хүснэгт/жагсаалт (утсан дээр карт): цаг (Улаанбаатарын цагаар `YYYY-MM-DD HH:mm:ss`), сурагч (нэр, имэйл), бодлого, `оноо / дээд оноо`, `давсан/нийт тест`.
- Мөр бүр `<details>`: Python → `<pre>` код; хэлхээ → гаралт бүрийн томьёо (§5) ба хаалганы тоо.
- Хуудаслалт: 100 мөр, «Өмнөх / Дараах» холбоос, «n–m / нийт» тоо.
- Хоосон бол «Илгээлт алга.»

### 2.2 «Хуулбар сэжиг» таб

- Бодлого тус бүрд (эрэмбээр) гарчиг, дор нь хосууд ижил төстэйн буурахаар, бодлого бүрт дээд тал нь 50 хос.
- Хос бүр: хоёр сурагчийн нэр, хувь (≥90% улаан, 70–89% шар шошго), хоёулангийнх нь оноо. `<details>` дэлгэхэд хоёр бодолт зэрэгцэн (утсан дээр дээр доороо).
- Бодлого бүрд «k бодолт хэт богино эсвэл уншигдахгүй тул харьцуулаагүй» гэсэн тоо (0 бол харуулахгүй).
- Хос олдохгүй бол «Ижил төстэй бодолт олдсонгүй.»
- Бодлого бүрийн доор анхааруулга. Хэлхээнд: «Хамгийн цөөн хаалгатай зөв хариулт ихэвчлэн ганц байдаг тул өндөр хувь гарах нь хуулбар гэсэн үг биш.» Python-д: «Энгийн бодлогын зөв хариултууд ихэвчлэн төстэй бичигддэг тул өндөр хувь гарах нь хуулбар гэсэн үг биш. Хоёр кодыг харьцуулж шийднэ үү.»
- Тооцоо хуудас ачаалах бүрд серверт хийгдэнэ; юу ч хадгалахгүй.

## 3. CSV

`GET /api/teacher/contests/[contestId]/export?type=results|attempts` (`src/app/api/teacher/contests/[contestId]/export/route.ts`).

- Эрх: нэвтрээгүй бол 401, багш/админ биш бол 403, тэмцээн байхгүй бол 404, `type` буруу бол 400.
- Хариу: `text/csv; charset=utf-8`, UTF-8 BOM (`﻿`, route нэмнэ — `toCsv` нэмэхгүй), мөр `\r\n`, `Content-Disposition: attachment; filename="<contestId>-dun.csv"` эсвэл `"<contestId>-oroldlogo.csv"`, `Cache-Control: no-store`.
- **Дүн** (`results`): `Байр, Нэр, Имэйл, <бодлого бүрийн гарчиг…>, Нийт`. Мөрийн дараалал, байр leaderboard-той ижил (`listParticipants`). Бодоогүй бодлого 0.
- **Бүх оролдлого** (`attempts`): `Цаг, Нэр, Имэйл, Бодлого, Төрөл, Оноо, Дээд оноо, Давсан тест, Нийт тест, Хариулт`. «Төрөл» нь `Python` эсвэл `Хэлхээ`; «Хариулт» нь Python код эсвэл хэлхээний томьёо (мөр бүр нэг гаралт). «Цаг» нь Улаанбаатарын цагаар `YYYY-MM-DD HH:mm:ss`. Нэр хоосон бол имэйлийг ашиглана.
- `src/lib/csv.ts`: `toCsv(rows: (string | number)[][]): string` — нүд бүр `"`-ээр хүрээлэгдэж, доторх `"` давхарлагдана. Текст нүд `=`, `+`, `-`, `@`, таб, `\r`-ээр эхэлбэл урд нь `'` нэмнэ (томьёоны халдлагаас сэргийлэх). Тоо хэвээр.

## 4. Хуулбар илрүүлэх

`src/lib/plagiarism/` — цэвэр функцууд (DB, React-гүй), нэгж тесттэй.

### 4.1 Python (`python.ts`)

1. **Токенжуулах** (regex-ээр, Python-ы бүрэн parser биш): тайлбар `#…` ба хоосон зай/мөр шилжилтийг хаяна. Тэмдэгт мөр (`'…'`, `"…"`, `'''…'''`, `"""…"""`, `f`/`r`/`b` угтвартай) → `S`. Тоо → `N`. Нэр (Unicode, `нийлбэр` ч мөн): Python түлхүүр үг болон суурь функц (`print`, `input`, `int`, `range`, `len`, `sum`, `min`, `max`… — жагсаалт `python.ts`-д тогтмол) хэвээр; `.`-ийн дараах нэр (метод, атрибут: `.append`, `.split`, `.count`) хэвээр; бусад нэр → `V` (тиймээс `count` нэртэй хувьсагч ч `V`). Оператор, хаалт тус бүр нэг токен.
2. **Хурууны хээ**: K = 5 токены дараалал бүрийг FNV-1a 32-bit hash; W = 4 цонхоор winnowing (цонх бүрийн хамгийн бага hash, тэнцвэл хамгийн баруун талынх). Үр дүн: hash-уудын олонлог.
3. **Эхлэлийн код**: бодлогын `starter_code`-ийн хээг хоёр талаас нь хасна.
4. **Оноо**: `|A ∩ B| / min(|A|, |B|)` (0–1). Жижиг бодолтын хэдэн хувь нь нөгөөд байгааг илэрхийлнэ — хуулаад дээр нь код нэмсэн ч өндөр гарна.
5. **Хэт богино**: эхлэлийн кодыг хассаны дараа хурууны хээ 8-аас цөөн (ойролцоогоор 5–6 мөрөөс богино) бол харьцуулахгүй. Жижиг бодлогын (жишээ нь «a + b») зөв хариултууд бүгд адилхан тул тэдгээрийг харьцуулбал бүх хос сэжигтэй гарна (2026-10-01, хэрэглэгчийн шийдвэр).

### 4.2 Хэлхээ (`circuit.ts`)

- Хадгалсан JSON-ийг `parseCircuit`-ээр уншина; уншигдахгүй бол «хэт богино»-той адил алгасна.
- Гарын үсэг `sig(end, d)`: оролтын терминал `in:A` → `A`; хаалга → `d = 0` бол зөвхөн төрөл, эс бөгөөс `ТӨРӨЛ(` + оролтуудын `sig(…, d-1)`-ийг **эрэмбэлж** таслалаар нийлүүлсэн + `)`. Холбогдоогүй оролт → `?`. Тойрог үүсвэл → `…`. Гүн D = 3.
- Олонлог (multiset): хаалга бүрийн `sig(g, 3)`, мөн гаралт бүрд `ГАРАЛТ=` + түүнийг тэжээж буй төгсгөлийн `sig`.
- Оноо: multiset Jaccard `Σ min(a, b) / Σ max(a, b)`.
- 2-оос цөөн хаалгатай хэлхээ → хэт богино.

### 4.3 Хос олох (`pairs.ts`)

```ts
interface Entry { uid: string; name: string; score: number; answer: string } // name: нэр эсвэл имэйл
findSimilarPairs(kind: "python" | "logic", entries: Entry[], opts: { starterCode?: string }):
  { pairs: { a: Entry; b: Entry; similarity: number }[]; skipped: number }
```

- Бүх хосыг (n(n−1)/2) харьцуулж, `similarity ≥ 0.70`-ийг буурахаар, дээд тал нь 50-ыг буцаана.
- Хувь нь `Math.round(similarity * 100)`; шошгоны өнгө энэ бүхэл хувиар (≥90 улаан, 70–89 шар).

## 5. Хэлхээ → томьёо

`src/lib/logic/formula.ts`: `circuitFormulas(circuit: Circuit, outputs: readonly string[]): string[]` — гаралт бүрд `Q = …` (`outputs` нь `logic_spec.outputs`).

- Оролт → нэр (`A`). `NOT x` → `NOT x` (x нийлмэл бол хаалтад). Хоёр оролттой хаалга → `(x AND y)`, порт 0, 1-ийн дарааллаар. Гадна хаалт хасагдана: `Q = (A AND B) OR NOT C`.
- Холбогдоогүй оролт/гаралт → `?`. Тойрог → `…`.
- Хаалганы тоо нь `circuit.gates.length`.
