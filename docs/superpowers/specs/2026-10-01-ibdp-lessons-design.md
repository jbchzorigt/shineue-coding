Эх материал: `D:\2026-2027 lessons\IBDP-CS\` — 19 сэдвийн хавтас (`A1.3 lessons` … `B3.2 lessons`), 80 PPTX хичээл (англи, 90 минутын төлөвлөгөө), 83 Python жишээ, сурах бичгийн 16 PDF бүлэг.

## Зорилго

Багшийн PPTX хичээлүүдийг платформ дээр сурагчид **бие даан**, сонирхолтойгоор судалж, **анхаарах зүйлсээ** мэдэж авах цэвэрхэн модулиуд болгох. Модуль бүр онолын хичээл, автоматаар дүгнэгдэх даалгавар, IB шалгалтын загвартай нэг асуулттай байна.

### Хэрэглэгчийн шийдвэрүүд

- Сэдэв бүр **1 модуль** (19), PPTX бүр модулийн дотор нэг **хэсэг**.
- Хэл: **монгол тайлбар + англи нэр томьёо** хаалтад; IB-ийн тушаалын үг (Explain, Construct…) англиар.
- Даалгавар: **хэсэг бүрт 2** автомат + **модуль бүрт 1** шалгалтын (theory).
- Нээгдэх дараалал: **хоёр зэрэгцээ зам** (A онол, B программчлал) — ижил «Дараалал» дугаартай хос хамт нээгдэнэ.
- HL хэсгүүд **HL тэмдэгтэй**, даалгавар нь бүх сурагчид тоологдоно.
- Одоогийн 01–07 модуль **хэвээр**; module-03-ийн силлабусын лавлагааг `B1.1` → `B2.1` болгоно.
- **Шаталсан** хүлээлгэн өгөлт (6 багц), эхний багцаар хэв маягийг хэрэглэгч батална.

### Хүрээнээс гадуур

- PPTX-ийн зураг, диаграмыг хуулах (хүснэгт, код, текстэн диаграмаар орлуулна).
- Сурах бичгийн текстийг хуулах — зөвхөн хуудасны лавлагаа (`Сурах бичиг: B2.2.3, 352–355-р тал`).
- Case Study (PDF 14), Internal Assessment (PDF 15)-ийн модуль.
- Сурагчийн SL/HL шинж, HL даалгаврыг заавал биш болгох.
- Видео, аудио.

### Амжилтын шалгуур

1. `/modules` дээр 19 шинэ модуль §1-ийн дарааллаар харагдана; хос бүр хамт нээгдэж, хоёуланг нь дуусгахад дараагийн хос нээгдэнэ.
2. Модуль бүрийн хичээл MDX алдаагүй харагдана, §2-ын загварын бүх хэсэгтэй.
3. ~179 даалгавар оруулагдана; **coding** даалгавар бүрийн жишиг бодолт бүх тестэд Piston дээр давна; **tracing**-ийн код бүр ажиллаж, хариутайгаа таарна.
4. `npm test` (контентын тест орно), `tsc`, `lint` (алдаа 0), `next build` бүгд амжилттай.
5. `import-ibdp` production-д ажиллахад 01–07 модуль болон багшийн UI-ийн засварт хүрэхгүй (тестээр батлагдана).
6. Багц бүрийг хэрэглэгч үзэж баталсан.

## 2. Хичээлийн загвар (`content/modules/<id>.mdx`)

Frontmatter: `module_id`, `syllabus_ref` (жишээ `A1.3`), `title`, `order`, `description` (модулийн жагсаалтад харагдах 1 өгүүлбэр).

Бие:

1. **Танилцуулга** — модуль юуны тухай, яагаад хэрэгтэй (амьдралын жишээ), хэсгүүдийн жагсаалт, ойролцоо хугацаа.
2. **Хэсэг бүр** (`## A1.3.1 Үйлдлийн системийн үүрэг`, HL бол гарчгийн ард `<HL />`):
   - `> 🎯 **Зорилго:**` — PPTX-ийн сурах зорилтууд IB тушаалын үгээр.
   - `### 🤔 Бодоод үзээрэй` — сонирхол татах асуулт / нөхцөл байдал; хариу `<details><summary>…</summary>…</details>`.
   - `### 📖 Гол ойлголт` — монгол тайлбар, жишээ, хүснэгт, текстэн диаграм; нэр томьёо анх гарахдаа `стек (stack)`.
   - `### 💻 Туршиж үзээрэй` — тухайн хавтасны Python жишээнээс цэгцэлж, тайлбарласан код (зөвхөн харуулах; сокет, thread зэргийг «өөрийн компьютер дээр ажиллуул» гэж тэмдэглэнэ). Жишээгүй хэсэгт алгасна.
   - `<Callout type="warning">` **⚠️ Анхаарах зүйлс** — түгээмэл буруу ойлголт, шалгалтын зөвлөгөө, тушаалын үгийн шаардлага.
   - `### 📝 Түлхүүр нэр томьёо` — `| Монгол | English | Тайлбар |`.
   - `### ✅ Өөрийгөө шалга` — 2–3 хурдан асуулт, хариу нь `<details>`-д.
   - Сурах бичгийн хуудасны лавлагаа (PPTX-д байгаа бол).
3. **Дүгнэлт** — гол санаанууд, **Шалгалтад анхаар**, дараагийн алхам (даалгавар руу урих).

MDX дүрэм: хаагдсан HTML таг, `{`/`}`/`<` зөв escape, код блокууд хэлтэй (` ```python `). Бүх файл `mdxError`-оор алдаагүй compile хийгдэнэ (§4 тест).

**`<HL />` компонент**: гарчгийн ард жижиг «HL» шошго (ягаан/violet), `src/components/mdx/mdx-content.tsx`-ийн components-д нэмэгдэнэ.

## 3. Даалгавар (`content/challenges/<id>.json`)

```jsonc
{
  "module_id": "b2-2",
  "challenges": [
    { "id": "b2-2-03-mcq", "section": "B2.2.3", "type": "mcq", "title": "…", "prompt": "…", "xp": 10,
      "options": ["…", "…", "…", "…"], "answer": 1, "hint": "…" },
    { "id": "b2-2-03-trace", "section": "B2.2.3", "type": "tracing", "title": "…", "prompt": "…```python\n…\n```", "xp": 15,
      "expected": "…", "hint": "…" },
    { "id": "b2-2-03-code", "section": "B2.2.3", "type": "coding", "title": "…", "prompt": "…", "xp": 20,
      "starter_code": "…", "tests": [{ "input": "…", "output": "…" }], "hidden_tests": [ … ],
      "solution": "…", "hint": "…" },
    { "id": "b2-2-exam", "type": "theory", "title": "…", "prompt": "… [4]", "xp": 20, "mark_scheme": "…" }
  ]
}
```

- Дараалал: массив дахь байрлал (`order` = индекс + 1).
- Хэсэг бүрт 2: онолын сэдэвт `mcq` + `tracing` (эсвэл 2 `mcq`); программчлалын сэдэвт (B1.1, B2.x, B3.x) нэг `mcq`/`tracing` + нэг `coding`.
- `coding`: хамгийн багадаа 2 харагдах + 2 нууц тест; `solution` зөвхөн шалгалтад, DB-д орохгүй.
- `theory`: IB тушаалын үг, оноо (`[4]`), mark scheme цэг тус бүр оноотой.
- SQL сэдэвт coding нь Piston-ы Python-д `sqlite3` байвал л; байхгүй бол SQL-ийн үр дүнг мөшгих tracing.
- XP: mcq 10, tracing 15, coding 20, theory 20.

## 4. Шалгалт

- **`src/lib/content/ibdp.ts`** — JSON-ийг уншиж шалгах, `Challenge`/`ChallengePrivate` болгох цэвэр функцууд.
- **Контентын тест** (`src/lib/content/ibdp.test.ts`, `npm test`-д орно): 19 MDX-ийн frontmatter (§1-тэй таарна), MDX compile, ID давхардаагүй, ID-ийн угтвар = module_id, mcq `answer` хүрээнд, tracing `expected` хоосон биш, coding ≥2+2 тест ба `solution`, theory `mark_scheme`, хэсэг бүрт ≥2 даалгавар, модуль бүрт 1 theory.
- **`scripts/check-solutions.ts`** — coding бүрийн `solution`-ыг бүх тестэд **Piston**-оор (жинхэнэ grader) ажиллуулна; tracing prompt доторх ` ```python ` кодыг ажиллуулж `expected`-тэй тулгана. Алдаатай бол жагсааж 1 кодоор гарна.

## 5. Оруулах

- **`scripts/seed-ibdp.ts`** (локал, `db:seed`-д нэмэгдэнэ) ба **`scripts/import-ibdp.ts`** (production) — хоёулаа `importIbdp()`-г ашиглана: зөвхөн §1-ийн 19 модуль ба тэдгээрийн даалгаврыг upsert хийнэ; module-03-ийн `syllabus_ref` нь `B1.1` байвал л `B2.1` болгоно; бусад модульд хүрэхгүй.
- Integration тест: 01–07 модулийн багшийн засвар `importIbdp()`-ийн дараа хэвээр.
- Production дараалал: **deploy** (`<HL />` кодтой) → `npm.cmd run script:prod -- scripts/import-ibdp.ts`. Эсрэгээр хийвэл хуучин код `<HL />`-г танихгүй.
