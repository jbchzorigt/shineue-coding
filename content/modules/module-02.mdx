# Компьютерийн бүтэц ба CPU

Компьютерийн төв боловсруулах нэгж (**CPU — Central Processing Unit**) нь программын зааврыг гүйцэтгэдэг "тархи" юм.

## CPU-ийн үндсэн хэсгүүд

| Хэсэг | Үүрэг |
| ----- | ----- |
| **ALU** (Arithmetic Logic Unit) | Арифметик болон логик үйлдлүүдийг гүйцэтгэнэ |
| **CU** (Control Unit) | Зааврыг тайлж, бусад хэсгүүдийг удирдана |
| **Registers** | CPU доторх хамгийн хурдан, жижиг санах ой |
| **Cache** | Байнга хэрэглэгддэг өгөгдлийн түр хадгалалт |

## Fetch–Decode–Execute цикл

CPU заавар бүрийг гурван үе шаттайгаар гүйцэтгэнэ:

1. **Fetch** — дараагийн зааврыг санах ойгоос авчирна
2. **Decode** — зааврыг тайлж юу хийхийг тодорхойлно
3. **Execute** — зааврыг гүйцэтгэнэ

<Callout type="info">
Энэ цикл секундэд тэрбум дахин давтагдана — 3 GHz гэдэг нь секундэд 3 тэрбум цикл гэсэн үг.
</Callout>

```text
┌─────────┐     ┌──────────┐     ┌───────────┐
│  Fetch  │ ──▶ │  Decode  │ ──▶ │  Execute  │
└─────────┘     └──────────┘     └───────────┘
     ▲                                  │
     └──────────────────────────────────┘
```

## Дүгнэлт

- CPU нь ALU, CU, регистр, кэшээс бүрдэнэ
- Заавар бүр fetch → decode → execute гэсэн циклээр гүйцэтгэгдэнэ
