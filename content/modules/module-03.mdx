# Хувьсагч ба өгөгдлийн төрөл

Программ бол өгөгдөл дээр хийгдэх үйлдлүүдийн дараалал. Өгөгдлөө **хувьсагчид** хадгална.

## Python-ийн үндсэн төрлүүд

| Төрөл | Жишээ | Тайлбар |
| ----- | ----- | ------- |
| `int` | `42` | Бүхэл тоо |
| `float` | `3.14` | Бодит тоо |
| `str` | `"Сайн уу"` | Тэмдэгт мөр |
| `bool` | `True` | Үнэн/худал |

```python
name = "Бат"
age = 17
gpa = 3.8
is_student = True

print(f"{name} нь {age} настай, голч {gpa}")
```

<Callout type="info">
Python-д хувьсагчийн төрлийг зарлах шаардлагагүй — утгаас нь автоматаар тодорхойлогдоно. Үүнийг dynamic typing гэнэ.
</Callout>

## Оролт ба гаралт

```python
name = input("Нэрээ оруулна уу: ")
year = int(input("Төрсөн он: "))
age = 2026 - year
print(f"Сайн уу {name}, та ойролцоогоор {age} настай.")
```

<Callout type="warning">
`input()` үргэлж тэмдэгт мөр (`str`) буцаадаг — тоон утга хэрэгтэй бол `int()` эсвэл `float()`-оор хөрвүүлэхээ мартав аа!
</Callout>

## Дүгнэлт

- Хувьсагч нь өгөгдлийг нэрлэж хадгална
- Үндсэн төрлүүд: `int`, `float`, `str`, `bool`
- `input()` нь `str` буцаана — шаардлагатай бол хөрвүүлнэ
