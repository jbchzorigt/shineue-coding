## B2.3.1 Дараалал: заавар бичигдсэн ээлжээрээ ажиллана

> 🎯 **Зорилго:** **Construct** programs that implement the correct sequence of code instructions to meet program objectives — программын зорилгыг хангах зөв ээлжтэй заавруудаас бүрдсэн программ зохиох. Энэ хэсгийн төгсгөлд та:
>
> - Дараалал гэж юу болох, мөрүүдийн ээлж үр дүнд яагаад нөлөөлдгийг тайлбарлана;
> - Буруу байрласан мөрийг олж, зөв газарт нь шилжүүлнэ;
> - Төгсгөлгүй давталт хэрхэн үүсдэг, зогсох нөхцөл үүнээс хэрхэн сэргийлдгийг тайлбарлана;
> - Харилцан түгжрэлийг (deadlock) тайлбарлаж, түүнээс зайлсхийх аргыг нэрлэнэ.

### 🤔 Бодоод үзээрэй

Өглөө яаран хувцаслахдаа гутлаа оймсноосоо өмнө өмсчихвөл яах вэ? Алхам бүр зөв, зөвхөн ээлж нь буруу — үр дүн нь инээдтэй. Программд ийм алдаа инээдтэй биш: үнэ буруу хэвлэгдэж, давталт хэзээ ч дуусахгүй болж болно. Кодгүйгээр хариулаарай:

1. Цай хийх алхмуудыг зөв ээлжинд оруул: цай уух · ус буцалгах · аяганд халуун ус хийх · аяганд цайны уут хийх.
2. `x = 2`, дараа нь `x = x * 3`, дараа нь `x = x + 1`. `x` хэд вэ? Сүүлийн хоёр мөрийг сольвол хэд болох вэ?
3. `price = 100`, дараа нь `print(price)`, дараа нь `price = price * 0.9`. Юу хэвлэгдэх вэ? Хямдарсан үнийг хэвлэхийн тулд юуг өөрчлөх вэ?

<details>
<summary>Хариу</summary>

1. Ус буцалгах → аяганд цайны уут хийх → халуун ус хийх → уух.
2. **7** (2 → 6 → 7). Сольвол 2 → 3 → **9**. Ижил мөрүүд, өөр ээлж — өөр үр дүн.
3. `100` хэвлэгдэнэ: хямдралыг хэвлэсний **дараа** тооцсон. `price = price * 0.9`-ийг `print`-ээс өмнө тавивал `90.0` гарна.

</details>

### 📖 Гол ойлголт

**Дараалал (sequence)** (B2.2.4-ийн queue биш) гэдэг нь заавар бүр бичигдсэн ээлжээрээ, нэг нэгээр, нэг удаа ажиллахыг хэлнэ. B1.1.4-т урсгал зургийн дүрсүүд нэг шугамаар дараалан явдаг байсан — Python-д мөрүүд дээрээс доош яг ингэж ажиллана. Сонголт ба давталт энэ урсгалыг салаалуулж, давтдаг (B2.3.2, B2.3.3) ч тэдгээрийн доторх мөрүүд мөн ээлжээрээ ажиллана. Ижил мөрүүдийг өөр ээлжээр бичвэл өөр, ихэнхдээ буруу үр дүн гарна.

#### Ижил мөрүүд, өөр ээлж

B2.1.1-ийн утга солих (swap) жишээнд `temp = a` эхэлж ажилладаг байсан. Сурах бичиг ижил гурван мөрийг өөр ээлжээр бичсэн хувилбарыг үзүүлдэг:

```python
a, b = 5, 7
a = b         # 7 is stored in a - the 5 is lost
temp = a      # temp = 7
b = temp      # b = 7
print(a, b)   # 7 7
```

| Код | a | b | temp |
|---|---|---|---|
| `a, b = 5, 7` | 5 | 7 | |
| `a = b` | **7** | 7 | |
| `temp = a` | 7 | 7 | 7 |
| `b = temp` | 7 | 7 | 7 |

B2.1.1-ийн мөшгих хүснэгт шиг мөр бүр нэг мөр код, нүдэнд тэр мөрийн **дараах** утга байна. `temp` хувьсагч байгаа ч хэтэрхий оройтож хэрэглэгдсэн: `a = b` ажиллахад 5 аль хэдийн устсан. Утга оноолт хуучин утгыг дарж бичдэг тул хэрэгтэй утгаа **эхлээд** хадгал.

#### Ээлж буруу бол юу болох вэ

IB-ийн хөтөлбөр зайлсхийх ёстой гурван алдааг нэрлэдэг бөгөөд гурвуулаа ихэвчлэн мөрүүдийн буруу ээлжээс үүсдэг. Аль нь ч Python-д алдааны мэдэгдэл гаргахгүй — программ зүгээр л буруу ажиллана.

| Үр дагавар | Юу болох вэ | Жишээ |
|---|---|---|
| Буруу гаралт (incorrect output) | Программ дуусна, гэвч хариу буруу | Хүргэлтийн төлбөрийг нэмэхээсээ өмнө нийт дүнг хэвлэх |
| Төгсгөлгүй давталт (infinite loop) | Давталт хэзээ ч зогсохгүй | Тоолуурыг өсгөх мөр дутуу эсвэл буруу газар |
| Харилцан түгжрэл (deadlock) | Программын хэсгүүд бие биенээ хүлээж, хэн нь ч урагшлахгүй | Хоёр хэсэг хоёр нөөцийг эсрэг ээлжээр авах |

#### Төгсгөлгүй давталт ба зогсох нөхцөл

`while` давталт нөхцөл нь үнэн байх хооронд давтагдана (B2.3.3-т дэлгэрэнгүй). Давталтын нэг удаагийн гүйлтийг **дамжилт (pass)** гэнэ. **Зогсох нөхцөл (termination condition)** гэдэг нь давталтыг зогсоох нөхцөл: доорх кодонд `i > 5` болох үе.

```python
i = 1
while i <= 5:          # the loop stops when i > 5
    print(i)
    i = i + 1          # moves i towards the termination condition
```

Энэ давталт 1-ээс 5 хүртэл хэвлээд зогсоно. Сүүлийн мөрийг устгавал, эсвэл хэзээ ч үнэн болохгүй `if` дотор байрлуулбал `i` 1 хэвээр үлдэж, `1` төгсгөлгүй хэвлэгдэнэ. Давталт бүрт өөрөөсөө асуу: **зогсох нөхцөл юу вэ, аль мөр биднийг түүн рүү ойртуулж байна вэ?**

#### Харилцан түгжрэл (deadlock)

Олон программ хэд хэдэн **thread**-ээр (нэг программын дотор зэрэг гүйцэтгэгддэг урсгал) ажилладаг бөгөөд файл, принтер зэрэг нөөцийг хуваалцдаг. Нөөцийг нэг удаад нэг л thread ашиглахын тулд түүний **түгжээг (lock)** авна. Хэрэв Worker 1 түгжээ A-г, Worker 2 түгжээ B-г аваад, тус бүр нөгөөгийнхөө түгжээг хүлээвэл:

```text
  Worker 1 ──хүлээнэ──▶ Lock B ──эзэмшигч нь──▶ Worker 2
      ▲                                           │
      └──эзэмшигч нь──── Lock A ◀──хүлээнэ────────┘
```

Сумыг дагаж унш: Worker 1 B-г хүлээж байна, B-г Worker 2 эзэмшдэг; Worker 2 A-г хүлээж байна, A-г Worker 1 эзэмшдэг. Хүлээлтийн тойрог хаагдсан тул хэн нь ч үргэлжилж чадахгүй. Нарийн гүүрэн дээр хоёр талаас зэрэг орж ирсэн хоёр машин хэн нь ч ухрахгүй байгаатай адил.

**Харилцан түгжрэл (deadlock)** гэдэг нь хоёр буюу түүнээс олон хэсэг тус бүр нэг нөөцийг барьсаар, нөгөөгийнхөө барьж буй нөөцийг хүлээж, хэн нь ч урагшилж чадахгүй байх төлөв. Программ унахгүй, алдааны мэдэгдэл ч гарахгүй — зүгээр л урагшлахаа болино. Зайлсхийх аргууд:

- **Нөөцийг үргэлж ижил ээлжээр ав:** хоёулаа эхлээд A, дараа нь B. Тэгвэл тойрог үүсэх боломжгүй — энд зааврын зөв ээлж өөрөө шийдэл болно.
- **Хүлээх хугацааг хязгаарла (time-out)** эсвэл шинэ нөөц хүлээхээсээ өмнө барьж буйгаа **сулла**.

Үйлдлийн систем deadlock-ийг хэрхэн шийддэгийг A1.3 модулийн A1.3.5 (HL) хэсэгт дэлгэрэнгүй.

### 💻 Туршиж үзээрэй

**1. Буруу байрласан мөрийг ол.** Программ гурван онооны дунджийг хэвлэх ёстой (хүлээгдэж буй хариу `70.0`). Ажиллуулахаасаа өмнө давталтыг мөшгиж, гаралтыг таамагла:

```python
total = 0
marks = [60, 70, 80]
for m in marks:
    average = total / len(marks)
    total = total + m
print("Average:", average)
```

```text
Average: 43.333333333333336
```

1. Дамжилт бүрт `average` ба `total` хэд болох вэ?
2. Аль мөр буруу газар байна, хаашаа шилжүүлэх вэ?
3. Python яагаад алдааны мэдэгдэл гаргаагүй вэ?

<details>
<summary>Хариу</summary>

| `m` | `average` (бодсон) | `total` (дараа нь) |
|---|---|---|
| 60 | 0 / 3 = 0.0 | 60 |
| 70 | 60 / 3 = 20.0 | 130 |
| 80 | 130 / 3 = 43.33… | 210 |

`average`-ийг давталтын **дотор**, сүүлийн оноо нэмэгдэхээс **өмнө** бодож байна. Мөрийг давталтын **дараа** (доголгүй, `print`-ийн өмнө) шилжүүлбэл 210 / 3 = `70.0`. Синтакс зөв, онцгой тохиолдол үүсээгүй — энэ бол логик алдаа (B2.1.4), зөвхөн мөшгилт ба тестээр илэрнэ.

</details>

**2. Төгсгөлгүй давталтын хамгаалалт.** Доорх давталтад `i`-г өсгөх мөр тайлбар (`#`) болсон. Демо гацахгүйн тулд 20 дамжилтын дараа `break` давталтыг зогсооно (`break` давталтаас шууд гаргана, B2.3.3-т дэлгэрэнгүй):

```python
i = 1
steps = 0
while i <= 5:
    steps = steps + 1
    if steps > 20:                     # safety net for this demo only
        print("Stopped: infinite loop - i never changes!")
        break
    # i = i + 1                        # the missing line
```

Ажиллуулахад `Stopped: infinite loop - i never changes!` хэвлэгдэнэ. Одоо сүүлийн мөрийн `#`-ийг арилгаад дахин ажиллуул. Юу хэвлэгдэх вэ, яагаад?

<details>
<summary>Хариу</summary>

Юу ч хэвлэгдэхгүй. `i` дамжилт бүрт 1-ээр өсөж, 5 дамжилтын дараа 6 болоход `i <= 5` худал болно. `steps` 5-д зогссон тул хамгаалалтын мэдэгдэлд хүрэхгүй.

</details>

<Callout type="warning">
**⚠️ Анхаарах зүйлс**

- **Утгыг дарж бичихээсээ өмнө хадгал.** Утга оноолт хуучин утгыг устгадаг: swap-д `temp = a` нь `a = b`-ээс өмнө байх ёстой.
- **Нийлбэр, тоолуурыг давталтын өмнө эхлүүл.** `total = 0` давталтын дотор байвал дамжилт бүрт 0 болно. Дундаж, нийт дүнг давталтын **дараа** бод.
- **Python ээлжийн алдааг мэдэгддэггүй.** Хариу буруу ч мэдэгдэл гарахгүй — мөшгих хүснэгт, түр `print`-ээр (B2.1.4) шалга.
- **`!=`-тэй давталтын нөхцөлөөс болгоомжил.** Алхам тэр утгыг «алгасвал» нөхцөл хэзээ ч худал болохгүй.
- **Deadlock ба төгсгөлгүй давталтыг бүү андуур.** Төгсгөлгүй давталт CPU-г ашиглан **ажилласаар** байна; deadlock-т хэсгүүд юу ч хийлгүй **хүлээнэ**.

</Callout>

**1.** Гурван тусдаа программ. Ажиллуулалгүйгээр, цаасан дээр шийд: аль нь хэзээ ч зогсохгүй вэ? Тус бүрд эхний дөрвөн дамжилтын дараах `i`-г бичээд, төгсгөлгүйг нь засна уу.

```python
# A
i = 1
while i <= 5:
    print(i)

# B
i = 10
while i > 0:
    i = i + 1

# C
i = 0
while i != 7:
    i = i + 2
```

<details>
<summary>Хариу</summary>

**Гурвуулаа** төгсгөлгүй!

- A: `i` = 1, 1, 1, 1 — өөрчлөгддөггүй. Давталт дотор `i = i + 1` нэм.
- B: `i` = 11, 12, 13, 14 — 0-ээс холдож байна. `i = i - 1` болго.
- C: `i` = 2, 4, 6, 8 — 7-г «алгасна». `while i < 7:` гэж шалга.

</details>

**2.** *Describe what is meant by deadlock and outline one way to avoid it.* [3]

## B2.3.2 Сонголт: if, elif, else

> 🎯 **Зорилго:** **Construct** programs utilizing appropriate selection structures — тохирох сонголтын бүтэц ашигласан программ зохиох. Энэ хэсгийн төгсгөлд та:
>
> - `if`, `if–else`, давхар `if`, `if–elif–else` бүтцийг Python-д бичнэ;
> - Харьцуулах (`<`, `<=`, `>`, `>=`, `==`, `!=`) ба логик (`and`, `or`, `not`) операторыг нөхцөлд хэрэглэнэ;
> - Сонголттой кодыг мөшгиж, аль салаа ажиллахыг таамаглана;
> - Нөхцөлүүдийн ээлжийг зөв салаа сонгогдохоор зохион байгуулна.

### 🤔 Бодоод үзээрэй

Гар утасны дансанд мөнгө байвал дуудлага холбогдоно, үгүй бол «Үлдэгдэл хүрэлцэхгүй» гэсэн мессеж ирнэ. Цахим дэвтэр таны оноог үсгэн дүн болгодог, нэвтрэх хуудас нууц үг зөв бол оруулж, буруу бол алдаа харуулна. Эдгээр нь программ **шийдвэр** гаргаж буй жишээ. `a = 7`, `b = 54` үед хариулаарай:

1. `(a < 9) and (b >= 30)` — True уу, False уу?
2. `(a == 3) or (b < 3)` — True уу, False уу?
3. `=` ба `==` юугаараа ялгаатай вэ? `if x = 5:` гэж бичвэл юу болох вэ?

<details>
<summary>Хариу</summary>

1. **True** — хоёр тал хоёулаа үнэн.
2. **False** — хоёр тал хоёулаа худал.
3. `=` утга **оноодог**, `==` хоёр утга тэнцүү эсэхийг **шалгадаг** (B2.1.1). `if x = 5:` бол `SyntaxError` — нөхцөлд `==` хэрэгтэй.

</details>

### 📖 Гол ойлголт

**Сонголт (selection)** гэдэг нь нэг буюу хэд хэдэн **нөхцөлөөс (condition)** хамааран аль заавар ажиллахыг (эсвэл юу ч ажиллахгүйг) шийддэг бүтэц. Нөхцөл бол `True` эсвэл `False` гарах илэрхийлэл. B1.1.4-ийн урсгал зургийн ромб (шийдвэр) Python-д `if` болно. Аль мөр аль **салаанд (branch)** хамаарахыг Python-д **догол мөр (indentation)** заана (Java-д `{ }` хаалт).

#### Сонголтын гурван хэлбэр

```python
purchase = 150
discount = 0                        # value for the False case
if purchase >= 100:                 # IF: one branch or nothing
    discount = purchase * 0.2
print("discount =", discount)       # not indented: runs either way

if purchase >= 100:                 # IF-ELSE: exactly one of two branches
    to_pay = purchase * 0.8
else:
    to_pay = purchase
print("to_pay =", to_pay)

score = 72
if score >= 80:                     # IF-ELIF-ELSE: only the FIRST True branch
    grade = "A"
elif score >= 65:
    grade = "B"
else:
    grade = "C"
print("grade =", grade)
```

```text
discount = 30.0
to_pay = 120.0
grade = B
```

Сурах бичгийн хөнгөлөлтийн жишээний гол санаа: `discount = 0` эхэнд байхгүй бол `purchase` 100-аас бага үед `discount` огт үүсэхгүй тул `print` `NameError` өгнө. `print` доголгүй тул нөхцөл үнэн ч, худал ч ажиллана. Хэрэглэгчээс уншвал `float(input())` гэж тоо болго.

Сүүлийн бүтцийг B1.1.4-ийн тэмдэглэгээгээр (◇ шийдвэр, `[ ]` үйлдэл, `(A)` холбогч):

```text
◇ score >= 80 ? ──TRUE──▶ [ grade ← "A" ] ──▶ (A)
      │ FALSE
      ▼
◇ score >= 65 ? ──TRUE──▶ [ grade ← "B" ] ──▶ (A)
      │ FALSE
      ▼
[ grade ← "C" ] ──▶ (A)
```

Нөхцөлүүд дээрээс доош шалгагдана. Эхний TRUE салаа ажиллаад, бусад нь **алгасагдана**: `score = 90` бол `score >= 65` огт шалгагдахгүй. Бүх салаа `(A)` цэгт нийлж, программ үргэлжилнэ. Python-д `elif` нь бусад хэлний `else if`.

Нөхцөлд B2.1.1-ийн харьцуулах ба логик операторуудыг хэрэглэнэ. `a = 8`, `b = 3` үед `a > 5 and b > 5` → `False` (`and`: хоёулаа үнэн байх ёстой), `a > 5 or b > 5` → `True` (`or`: дор хаяж нэг нь), `not (a == b)` → `True` (`not` эсрэгээр нь болгоно). Python-д хязгаарыг `1 <= a <= 10` гэж холбож бичиж болно — `1 <= a and a <= 10`-тэй ижил.

#### Давхар if ба нөхцөлийн ээлж

**Давхар if (nested if)** — `if` дотор өөр `if`. Дүрэм: 100 ба түүнээс дээш худалдан авалтад гишүүн 20%, гишүүн биш 10% хөнгөлөлт авна.

```python
value, member = 150, True
if value >= 100:
    if member:                  # checked only when value >= 100
        pay = value * 0.8
    else:
        pay = value * 0.9
else:
    pay = value
print("pay =", pay)               # pay = 120.0
```

Ижил дүрмийг `and` ба `elif`-ээр хавтгай бичиж болно — 💻 дээрх `to_pay` яг ижил хариу өгнө. `if member == True:` гэхийн оронд `if member:` гэж бичдэг: `member` өөрөө Boolean утга.

**Нөхцөлийн ээлж.** `elif` гинж эхний True нөхцөл дээр зогсдог тул хамгийн **хатуу** нөхцөлийг (жишээ нь хамгийн өндөр хил) эхэнд тавь. `score >= 50`-ийг эхэнд нь тавивал 95 оноо ч «C» авна: эхний нөхцөл аль хэдийн үнэн.

### 💻 Туршиж үзээрэй

Нөхцөлүүдийг энд **функц** дотор бичсэн: `grade(95)` нь 95-ын үсгэн дүнг `return`-ээр буцаана (B2.1.1-д товч үзсэн, B2.3.4-т дэлгэрэнгүй). `for value, member in [...]` нь хос утга бүрийг хоёр хувьсагчид задална. Ажиллуулахаасаа өмнө мөр бүрийг таамагла:

```python
def to_pay(value, member):
    if value >= 100 and member:
        return value * 0.8
    elif value >= 100 and not member:
        return value * 0.9
    else:
        return value

def grade(score):
    if score >= 80:
        return "A"
    elif score >= 65:
        return "B"
    elif score >= 50:
        return "C"
    else:
        return "U"

for value, member in [(150, True), (150, False), (80, True), (100, False)]:
    print("value", value, "member", member, "-> pay", to_pay(value, member))
for s in [95, 80, 79, 50, 12]:
    print(s, "->", grade(s))
```

```text
value 150 member True -> pay 120.0
value 150 member False -> pay 135.0
value 80 member True -> pay 80
value 100 member False -> pay 90.0
95 -> A
80 -> A
79 -> B
50 -> C
12 -> U
```

1. `(100, False)` яагаад `90.0` вэ? `(80, True)` яагаад `.0`-гүй вэ?
2. `grade()` дотор `score >= 50` салааг хамгийн эхэнд шилжүүлбэл аль оноонууд буруу дүн авах вэ?

<details>
<summary>Хариу</summary>

1. 100 нь `>= 100`-д тэнцэнэ (хил орно), гишүүн биш тул 10%: 100 × 0.9 = `90.0`. 80 үед аль ч хөнгөлөлт хамаарахгүй тул `value` өөрөө (бүхэл тоо) буцна — үржүүлээгүй тул бутархай болоогүй.
2. 95, 80, 79, 50 бүгд «C» болно — эхний нөхцөл тэдэнд үнэн. Зөвхөн 12 «U» хэвээр.

</details>

<Callout type="warning">
**⚠️ Анхаарах зүйлс**

- **`elif`-ийн ээлж чухал.** Зөвхөн эхний True салаа ажиллана — хамгийн хатуу нөхцөлийг эхэнд тавь.
- **Хил дээрх утгаар шалга.** `>=` ба `>`-ийн ялгаа яг хил дээр л харагдана: 79, 80, 81-ээр туршиж үз.
- **`or`-ийн хоёр тал бүрэн нөхцөл байна.** `if answer == "yes" or "y":` үргэлж үнэн: Python хоосон биш текст ба 0 биш тоог нөхцөлд **үнэн** гэж үздэг. `if answer == "yes" or answer == "y":` гэж бич.
- **Тусдаа `if` ≠ `elif`.** Гурван тусдаа `if` гурвуулаа шалгагдаж, 95 оноонд A, B, C-г бүгдийг хэвлэж болно.
- **Зөвхөн нэг салаанд утга авдаг хувьсагчид анхны утга өг** (`discount = 0`), эс бөгөөс `NameError`.
- **`eval(input())`-ийг бүү хэрэглэ.** Сурах бичгийн нэг жишээ Boolean-ийг ингэж уншдаг ч `eval` хэрэглэгчийн бичсэн дурын Python кодыг ажиллуулна — аюултай. `answer.lower() == "yes"` гэж харьцуул.

</Callout>

## B2.3.3 Давталт: for ба while

> 🎯 **Зорилго:** **Construct** programs that utilize looping structures to perform repeated actions — давтагдах үйлдлийг давталтаар гүйцэтгэдэг программ зохиох. Энэ хэсгийн төгсгөлд та:
>
> - `range(start, stop, step)`-тэй тоолууртай давталт бичнэ;
> - Урьдчилсан нөхцөлтэй (`while`) ба дараах нөхцөлтэй (`while True` + `break`) давталт бичнэ;
> - Давталт дотор болон давталтын нөхцөлд сонголт, харьцуулах ба логик оператор хэрэглэнэ;

### 🤔 Бодоод үзээрэй

Мобайл банкны апп ПИН кодыг буруу оруулбал дахин асуудаг, гэхдээ гурав дахь буруугийн дараа түгжинэ. Хэдэн удаа асуухаа апп урьдчилан мэдэхгүй — та хэзээ зөв оруулахаас хамаарна. Харин «Ангийн 30 сурагч бүрт мессеж илгээх» ажлын давталтын тоо урьдчилан мэдэгдэнэ. Хариулаарай:

4. Нууц үг зөв болтол асуух давталт хэдэн удаа давтагдахыг урьдчилан мэдэх үү?

<details>

2. `[1, 4, 7]` — 10 орохгүй.

4. Үгүй — тиймээс тоолууртай биш, нөхцөлтэй (`while`) давталт хэрэгтэй.

### 📖 Гол ойлголт

**Давталт (loop, iteration)** гэдэг нь кодын блокийг давтан гүйцэтгэдэг бүтэц. Давталт кодыг богино болгож, давталтын тоог оролт эсвэл нөхцөлөөс хамааруулж, өөрчлөхөд амар болгоно. Сурах бичиг давталтын гурван төрлийг ялгадаг:

| Төрөл | Python | Нөхцөл хэзээ шалгагдах | Хамгийн цөөндөө | Жишээ хэрэглээ |
|---|---|---|---|---|
| Тоолууртай давталт (count-controlled loop) | `for i in range(...)` | Давталтын тоо эхлэхээс өмнө мэдэгдэнэ | Тогтсон тоогоор | 1-ээс 100 хүртэл хэвлэх, жагсаалтын элемент бүр |
| Урьдчилсан нөхцөлтэй давталт (pre-condition loop) | `while үргэлжлэх_нөхцөл:` | Дамжилт бүрийн **өмнө** | 0 удаа | Оролт зөв болтол дахин асуух |
| Дараах нөхцөлтэй давталт (post-condition loop) | `while True:` … `if зогсох_нөхцөл: break` | Дамжилт бүрийн **төгсгөлд** | 1 удаа | Цэс харуулаад «Дахин тоглох уу?» гэж асуух |

Сурах бичиг дараах нөхцөлтэй давталтыг REPEAT–UNTIL гэж нэрлэдэг. Python-д тусгай бүтэц байхгүй (Java-д `do … while`) тул `while True` ба төгсгөлийн `break`-ээр дуурайна. **`break`** хамгийн ойрын (өөрийг нь агуулсан) давталтаас шууд гаргана.

#### Тоолууртай давталт: `range(start, stop, step)`

| Код | Утгууд | Тайлбар |
|---|---|---|
| `range(5)` | 0 1 2 3 4 | 0-ээс эхэлж, 5 удаа |
| `range(1, 6)` | 1 2 3 4 5 | start орно, stop (6) **орохгүй** |
| `range(1, 10, 2)` | 1 3 5 7 9 | алхам 2: сондгой тоонууд |
| `range(5, 0, -1)` | 5 4 3 2 1 | сөрөг алхам буурна; 0 орохгүй |
| `range(3, 3)` | (хоосон) | start = stop бол 0 удаа |

1-ээс n хүртэл (n орно) бол `range(1, n + 1)`. Буурахдаа 1 хүртэл бол `range(n, 0, -1)`. Сондгой тоог хоёр янзаар гаргаж болно: `range(1, 100, 2)`, эсвэл `range(1, 100)` дотор `if i % 2 == 1:`.

#### Нөхцөлтэй давталт: `while`

**Шалгах (validation)** — оролт утга учиртай, боломжийн мужид байгаа эсэхийг шалгах (B2.1.3). **Баталгаажуулах (verification)** — өгөгдлийг зөв оруулсан, хуулсан эсэхийг шалгах; жишээ нь нууц үгийг хоёр удаа оруулж харьцуулах. Хоёуланд нь урьдчилсан нөхцөлтэй давталт тохирно:

```python
password = input("New password: ")
check = input("Re-enter the password: ")
while check != password:                # checked BEFORE each pass
    check = input("Re-enter the password: ")
print("The two passwords matched")
```

Эхний давтан оруулалт зөв бол давталтын бие **0 удаа** ажиллана. Тоолууртай давталт бүрийг `while`-аар бичиж болно: B2.3.1-ийн `while i <= 5:` давталт бол `for i in range(1, 6):`-ийн `while` хувилбар.

#### Нөхцөл давталтыг удирдана

Нөхцөл давталтыг хоёр газраас удирддаг. Давталтын **нөхцөлд** — үргэлжлэх эсэхийг (`and`, `or`, `not`); давталтын **дотор** — дамжилт бүрт юу хийхийг (`if`). Таах тоглоом: нууц тоо 7, хамгийн ихдээ 3 оролдлого.

```python
secret = 7
attempts = 0
guess = 0
while guess != secret and attempts < 3:      # two ways to stop
    guess = int(input())
    attempts = attempts + 1
if guess == secret:                           # WHY did the loop stop?
    print("Correct!")
else:
    print("The game is locked. Try again later!")
```

Давталт таасан **эсвэл** 3 оролдлого дууссан үед зогсоно. Зогссоны дараа **аль** шалтгаанаар зогссоныг `if`-ээр шалгаж байгааг анхаар. Энд `for` тохиромжгүй: зөв таавал эрт зогсох ёстой.

#### Давхар давталт (nested loop)

Давталт дотор давталт: гаднах давталтын **дамжилт бүрт** доторх давталт эхнээс нь дуустал бүтэн ажиллана.

```python
for i in range(1, 4):           # outer loop: 3 passes
    for j in range(1, 3):       # inner loop: 2 passes for EACH i
        print(i, "x", j, "=", i * j)
```

## B2.3.4 Функц ба модульчлал

> 🎯 **Зорилго:** **Construct** functions and modularization — функц бичиж, программыг бие даасан хэсгүүдэд хуваах. Энэ хэсгийн төгсгөлд та:

### 📖 Гол ойлголт

- **Процедур (procedure)** — нэр өгсөн, хэрэгтэй үед нь дууддаг заавруудын багц; утга **буцаадаггүй** (хэвлэх, өгөгдөл өөрчлөх зэрэг ажил хийнэ).
- **Функц (function)** — утга **буцаадаг** нэрлэсэн заавруудын багц; буцсан утгыг хэвлэх эсвэл илэрхийлэлд хэрэглэж болно.

B2.1.1-д `def`-ээр бичсэн бүхнийг «функц» гэсэн. Python-д хоёулаа `def`-ээр бичигдэх бөгөөд `return`-гүй бол `None` («утга байхгүй» гэсэн тусгай утга) буцаадаг. IB-ийн ялгаа нь утга **буцаах эсэх**: үүнийг шалгалтад ялгаж бич.

#### «Хоёр тоо нэмэх»-ийн гурван хувилбар

```python
# Version 1: no subprogram - to reuse it, copy the lines again
no1, no2 = 3, 4
print("The result is", no1 + no2)

# Version 2: a PROCEDURE with parameters - reusable, but it only prints
def show_sum(no1, no2):
    print("The result is", no1 + no2)

# Version 3: a FUNCTION - it hands the value back
def add(no1, no2):
    return no1 + no2

show_sum(3, 4)
new_val = 3 + add(3, 4)          # a returned value can be used in an expression
print("new_val =", new_val)
```

```text
The result is 7
The result is 7
new_val = 10
```

Хувилбар 1 нэг л удаа ажиллана: дахин хэрэглэхэд мөрүүдийг хуулна. Процедурыг өөр утгуудаар дахин дуудаж болох ч зөвхөн хэвлэнэ. Функц хариугаа **буцааж өгдөг** тул бусад код түүгээр үргэлжлүүлэн тооцоолно.

#### Параметр, аргумент, буцах утга

- **Параметр (parameter)** — тодорхойлолтод (`def` мөрөнд) нэрлэсэн, утга хүлээн авах локал хувьсагч: `no1`, `no2`.
- **Аргумент (argument)** — **дуудахдаа** өгөх бодит утга: `add(3, 4)`-ийн 3 ба 4.
- **`return`** — утгыг дуудсан газар руу буцааж, функцийг **тэр даруй** дуусгана; түүний доорх мөр ажиллахгүй.

| Дуудлага | `no1` | `no2` | Буцсан утга |
|---|---|---|---|
| `add(3, 4)` | 3 | 4 | 7 |
| `add(7, 10)` | 7 | 10 | 17 |
| `add("3", "4")` | `"3"` | `"4"` | `"34"` — текст залгагдана! |

Мөр бүр нэг дуудлага: аргументууд параметрүүдэд **ээлжээрээ** (эхнийх нь эхнийхэд) оноогдож (`no1 = 3`, `no2 = 4` гэсэнтэй адил), функц буцах утгыг бодно. Сүүлийн мөр нь `input()`-ийг `int()` болгохоо мартвал юу болохыг харуулна (B2.1.1).

#### Хүрээ ба гаж нөлөө

Параметр ба функц доторх хувьсагч бүр **локал**: функц дуусахад устана (B2.1.1). Өгөгдлийг параметрээр **оруулж**, үр дүнг `return`-ээр **гаргавал** функц бие даасан, шалгахад амар болно. Харин функц глобал хувьсагчийг `global`-аар өөрчилбөл, эсвэл параметрээр ирсэн жагсаалтад `append` хийвэл гаднах өгөгдөл өөрчлөгдөнө — энэ бол **гаж нөлөө (side effect)**. Ийм нөлөөг аль болох цөөл.

#### Модульчлал

B1.1.2-т **задлах (decomposition)** нь **асуудлыг** дэд асуудлуудад хуваах гэж үзсэн. Кодонд дэд асуудал бүрийг тусдаа функц болгон бичихийг **модульчлал (modularization)** гэнэ (B1.1.2-т modularity гэж дурдсан). Жишээ: сурагчийн дундаж ба дүнгийн тайлан.

```python
def average(marks):
    return sum(marks) / len(marks)

def grade(score):
    if score >= 80:
        return "A"
    elif score >= 65:
        return "B"
    elif score >= 50:
        return "C"
    return "U"

def report(name, marks):                 # uses the two functions above
    avg = average(marks)
    print(name, round(avg, 1), grade(avg))

report("Anu", [72, 85, 90])
report("Bat", [40, 55, 48])
```

```text
Anu 82.3 A
Bat 47.7 U
```

`grade` дотор `return "U"`-д `else` хэрэггүй: өмнөх `return` аль нэг нь ажилласан бол функц аль хэдийн дууссан. `report` нь «юу хийх»-ийг хоёрхон мөрөөр уншигдахуйц бичсэн; «яаж»-ийг `average` ба `grade` нуусан.

| Давуу тал | Яагаад |
|---|---|
| Дахин ашиглах | Нэг удаа бичиж шалгаад, өөр аргументаар хаанаас ч дуудна — хуулж буулгах хэрэггүй, код богино |
| Засварлахад хялбар (maintainable) | Алдаа, өөрчлөлтийг функц дотор нэг газар засахад бүх дуудлагад хүрнэ |
| Тестлэх, алдаа олох | Функц бүрийг тусад нь шалгаж, алдааг жижиг хэсэгт хайна |
| Багаар ажиллах | Программист бүр өөр функц, модуль бичиж, дараа нь нэгтгэнэ |
| Уншигдах байдал | `grade(avg)` гэсэн нэр олон мөр кодыг нэг үгээр илэрхийлнэ |

    result = 1
    for i in range(2, n + 1):
        result = result * i

    word = word.lower()
    for i in range(len(word) // 2):
        if word[i] != word[len(word) - 1 - i]:
            return False              # one mismatch is enough: stop at once
    return True                       # reached only if no mismatch was found

def show_sum(no1, no2):

## Дүгнэлт

- **Дараалал:** заавар бичигдсэн ээлжээрээ нэг удаа ажиллана. Утгыг дарж бичихээсээ өмнө хадгал; давталт бүрт зогсох нөхцөл рүү ойртуулах мөр байлга; deadlock-оос нөөцийг ижил ээлжээр авч сэргийл.
- **Сонголт:** `if`, `if–else`, давхар `if`, `if–elif–else`. `elif` гинж эхний True салаан дээр зогсдог тул хамгийн хатуу нөхцөл эхэнд. `or`, `and`-ийн хоёр тал бүрэн нөхцөл.
- **Давталт:** тоолууртай (`for` + `range(start, stop, step)`, stop орохгүй), урьдчилсан нөхцөлтэй (`while`, 0+ удаа), дараах нөхцөлтэй (`while True` + `break`, 1+ удаа). Давхар давталтад доторх нь гаднах дамжилт бүрт бүтэн ажиллана.
- **Функц:** процедур утга буцаадаггүй, функц буцаадаг. Параметр — тодорхойлолтод, аргумент — дуудлагад. `return` функцийг дуусгана; `print` ≠ `return`. Модульчлал: дахин ашиглах, засварлах, тестлэх, багаар ажиллахад хялбар.

**Шалгалтад анхаар:**

- **Construct** (бүх хэсэг): тоолуур, нийлбэрийг давталтын өмнө эхлүүл; хил дээрх утгыг (`>=` эсвэл `>`) асуултын дагуу яг бич; дуудсан код утгыг хэрэглэх бол `return`.
- Давталтын **төрлийг** нэрлэ (count-controlled, pre-condition, post-condition) ба шалтгааныг бич — «a FOR loop» хангалтгүй.
- **Explain** (функцийн давуу тал): давуу тал бүрийг нэрлээд зогсохгүй, яагаад тус болохыг бич.
- Мөшгихдөө: давхар давталтад доторх давталт гаднах дамжилт бүрт бүтэн ажиллана; функцийн дуудлагад аргумент параметрт ээлжээрээ оноогдож, хаалтан доторх дуудлага эхэлж бодогдоно.
- Байнга гардаг алдаа: нэгээр алдах, төгсгөлгүй давталт, `=` ба `==`, `elif`-ийн буруу ээлж, `print`-ийг `return`-ээр андуурах.
