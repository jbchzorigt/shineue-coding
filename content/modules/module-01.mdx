# Хоёртын тооллын систем

Компьютерийн хамгийн гүн түвшинд бүх өгөгдөл — текст, зураг, дуу, программ — зөвхөн **0 ба 1** гэсэн хоёр цифрээр илэрхийлэгддэг. Үүнийг **хоёртын (binary) тооллын систем** гэнэ.

<Callout type="info">
IBDP шалгалтад тоог аравтаас хоёртод, хоёртоос аравтад болон арван зургаатад (hexadecimal) хөрвүүлэх бодлого байнга ордог. Хөрвүүлэлтийг калькуляторгүй хийж сурах шаардлагатай!
</Callout>

## Бит ба байт

- **Бит (bit)** — мэдээллийн хамгийн жижиг нэгж: `0` эсвэл `1`
- **Байт (byte)** — 8 бит. Нэг байтаар 2⁸ = 256 өөр утга илэрхийлж чадна
- Үүнээс цааш: килобайт (KB), мегабайт (MB), гигабайт (GB)...

## Аравтаас хоёртод хөрвүүлэх

Аравтын тоог 2-т хувааж, үлдэгдлүүдийг доороос нь дээш уншина. Жишээ нь **13**-ыг хөрвүүлье:

| Үйлдэл | Ноогдвор | Үлдэгдэл |
| ------ | -------- | -------- |
| 13 ÷ 2 | 6        | **1**    |
| 6 ÷ 2  | 3        | **0**    |
| 3 ÷ 2  | 1        | **1**    |
| 1 ÷ 2  | 0        | **1**    |

Үлдэгдлүүдийг доороос дээш уншвал: **13₁₀ = 1101₂**

## Хоёртоос аравтад хөрвүүлэх

Бит бүр 2-ын зэрэгт харгалзана (баруунаас зүүн тийш 2⁰, 2¹, 2², ...):

```text
1    1    0    1
2³   2²   2¹   2⁰
8  + 4  + 0  + 1  = 13
```

## Python-оор шалгах

Хөрвүүлэлтээ Python ашиглан шалгаж болно:

```python
# Аравтаас хоёртод
print(bin(13))        # 0b1101

# Хоёртоос аравтад
print(int("1101", 2)) # 13

# Өөрөө бичвэл:
def to_binary(n: int) -> str:
    digits = ""
    while n > 0:
        digits = str(n % 2) + digits
        n = n // 2
    return digits or "0"

print(to_binary(13))  # 1101
```

<Callout type="warning">
`bin()` функц үр дүнгийн урд `0b` угтвар залгадаг гэдгийг санаарай — шалгалтын хариултад зөвхөн цифрүүдийг нь бичнэ.
</Callout>

## Дүгнэлт

- Компьютер бүх өгөгдлийг хоёртын системд хадгална
- Аравтаас хоёртод: 2-т хувааж үлдэгдлүүдийг доороос дээш уншина
- Хоёртоос аравтад: бит бүрийг 2-ын зэрэгтээр үржүүлж нэмнэ

Дараагийн шатанд энэ мэдлэгээ ашиглан дасгал бодлогуудыг бодож, модулиа дуусгаарай.
